# NEXUS 2100

## Project Description

NEXUS 2100 is a futuristic AI-powered multimodal transportation
planning and live-tracking web application.

The experience represents transportation technology in the year 2100.

The application should feel like a professional AI mobility operating
system rather than a normal transportation website.

---

## Competition Priorities

The project must strongly focus on:

1. Usability
2. Aesthetics
3. Innovation
4. Accessibility
5. Functionality
6. Mobile responsiveness

Functionality and usability must never be sacrificed for visual effects.

---

## Required Screens

The website contains three primary screens.

### 1. Home

Route:

/

Purpose:

Allow users to search for journeys involving futuristic multimodal
transportation including:

- autonomous buses
- future trains
- air transportation
- smart roads

### 2. Journey Details

Route:

/journey

Purpose:

Display:

- selected route
- transport modes
- transfer information
- arrival times
- predicted delays
- AI route recommendations
- smart rebooking

### 3. Live Tracking

Route:

/tracking

Purpose:

Provide a futuristic map-based journey tracking experience.

Display:

- current vehicle location
- route progress
- estimated arrival
- vehicle speed
- AI prediction confidence
- journey status

---

## Technology Stack

Use:

- React
- Vite
- Three.js
- React Three Fiber
- Drei
- Motion
- React Router
- Zustand
- Lucide React
- Tailwind CSS

Avoid installing unnecessary additional dependencies.

---

## Visual Style

The interface represents the year 2100.

Use:

- futuristic dark environment
- professional glass interfaces
- holographic elements
- cyan lighting
- subtle violet AI elements
- futuristic transportation
- 3D environments
- intelligent animations
- premium typography
- clean spacing

Avoid a gaming-style RGB interface.

Avoid excessive glow.

The final application should feel sophisticated and believable.

---

## Color Palette

Background:
#030711

Surface:
#081525

Primary Cyan:
#39E7FF

AI Violet:
#8B5CFF

Success:
#42FFB4

Warning:
#FFB84D

Primary Text:
#F4FAFF

Secondary Text:
#8CA5BA

Do not introduce unnecessary colors.

---

## 3D Philosophy

Use React DOM for important interface elements:

- text
- forms
- search
- buttons
- navigation
- cards
- accessibility controls

Use React Three Fiber / Three.js for:

- futuristic city
- trains
- autonomous vehicles
- air taxis
- holographic environments
- route visualization
- lighting
- particles
- camera animations

Do not create important buttons or forms as 3D objects.

3D must enhance usability rather than reduce usability.

---

## Artificial Intelligence Features

The prototype should visually demonstrate:

- AI route optimization
- predictive delays
- smart rebooking
- personalized journey suggestions
- accessibility-aware routing

Demo data may be simulated.

The UI must not falsely claim simulated data is real-world live data.

---

## Accessibility

Support:

- keyboard navigation
- visible focus indicators
- sufficient contrast
- readable typography
- large touch targets
- semantic HTML
- ARIA labels where required
- reduced-motion mode
- high-contrast mode
- simplified interface
- step-free journey preference

---

## Responsive Design

Every primary screen must work on:

- desktop
- laptop
- tablet
- mobile

Reduce expensive 3D rendering and effects when necessary on smaller
or lower-performance devices.

---

## Performance

Avoid unnecessarily large 3D assets.

Prefer optimized GLB models.

Lazy-load expensive assets where appropriate.

The normal interface must remain functional while 3D content loads.

---

## Core Rule

Functionality first.

Usability second.

Accessibility third.

Visual polish and 3D immersion should enhance these foundations.

Every visible primary button should perform a meaningful action.
